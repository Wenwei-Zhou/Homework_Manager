### Study Manager

A React-based web application designed to help students organize their learning — from online courses and assignments to timetables and performance tracking.

🌟 
# Overview

Study Manager is a productivity-focused learning management web application built with React and Material UI.
It allows students to efficiently manage their study schedule, view course progress, track assignments, and monitor academic performance — all in one intuitive interface.

The application integrates online tutorials, time management, and data visualization to make learning structured and engaging.

🚀 
# Features
🏫 Home – Online Learning Dashboard

Displays multiple subjects (English, Math, Physics, Programming, Chemistry).

Each subject includes recommended tutorials with images, titles, and descriptions.

Dynamic subject switching and responsive layout.

Integrated message panel and calendar on the right side.

📘 
# Course Management

Manage course progress and study duration.

Add, edit, or delete assignments and mark them as completed.

Tasks include priority, due date, and course tags.

Automatically calculates:

✅ 
# Completed assignments count

⏱️ 
# Total study time

📈 
# Average course progress

⏰ 
# Timetable

Interactive weekly timetable (Mon–Sun × hourly slots).

Add courses with title, color, and duration.

Click an empty slot to add a course; click ❌ to remove it.

Visually highlights occupied time slots.

💬 
# Additional Features

Modal-based Login & Signup forms.

Context-based UI state management for user progress.
